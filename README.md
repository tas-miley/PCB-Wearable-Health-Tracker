# PCB-Wearable-Health-Tracker
PCB design to run the firmware for the Wearable Health Tracker project. The goal of this PCB is to support SPO2 and IMU sensors, BLE communication, and LiPo battery power/charging. It's also designed to be ~1 inch x 1 inch to support wrist wearability.

Completed:
- Component selection (Max30102, LSM6DSOX, nRF52833, voltage regulators)
- Battery Selection (LiPo 150mAh)
- Connector choice (USB-C for charging, battery connector, Tag Connect for programming)
- Initial 2 layer trace layout
